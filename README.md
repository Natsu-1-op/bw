# 随身粤语 · 原声音频库

包含初级 10 单元、中级 5 单元，共 643 条播放条目、631 个独立 MP3，约 112 分钟原声。音频和课文数据均已保存到本地，页面播放不再依赖原站。

## 使用

打开 `index.html` 即可在电脑上学习。支持按课程和章节筛选、搜索、收藏、显示或隐藏释义与粤拼、展开整段课文、0.6–1.5 倍速、单句循环、连续播放、单条下载，以及记住上次播放位置。收藏与进度保存在当前浏览器。

长对话和短文保留整段原声；原站提供的逐句录音按句独立显示。

## GitHub Pages

1. 解压 `github-pages.zip`。
2. 把解压得到的 `index.html`、`data/`、`audio/`、`.nojekyll` 等文件放到 GitHub 仓库根目录。不要只上传 ZIP 文件。
3. 在 **Settings → Pages** 选择 **Deploy from a branch → main → /(root)**，保存。
4. 等待站点地址出现后，用手机打开即可。

不需要 Node.js、构建步骤或后端；所有资源使用相对路径，可用于 GitHub Pages 的仓库子路径。

## 维护

`source/` 保存原课程页面，`tools/sync_audio.py` 可依据页面重新生成音频库。已有音频会复用；只把通过音频格式识别的文件纳入库中。

```sh
python3 tools/sync_audio.py
```

原站有访问验证；直接抓取被拦截时，可通过同一原站的浏览器请求临时导出配合脚本的 `--request-har` 参数下载（需安装 `curl_cffi`）。浏览器请求导出文件不应放入仓库或发布包。

发布包仅包含播放器、课程清单、MP3 和本说明，不包含抓取请求或浏览器会话数据。

## 标音与手机端更新

“粤语语音特点”的 41 条播放条目（33 个独立音频文件）已补充例字、粤拼声调和发音提示；需要比较普通话的例子另行标注普通话拼音。补注采用香港语言学学会粤拼方案，并与中大粤语审音配词字库核对。名称“屈臣氏”的氏按原课变调标 si2，附常用字音 si6 的说明。

补注数据保存在 `data/phonetics.json`，由 `tools/phonetics.py` 加入课程清单；重新抓取时也会保留这些补注。核对报告见开发目录的 `data/pronunciation-validation.json`。

手机端增加可收起的播放器、44 像素的播放与收藏按钮、16 像素的筛选和搜索输入，以及随播放器高度变化的底部留白。已检查 320、390、430、768、1280 像素宽度，无横向溢出；并验证补注录音播放、0.8 倍速、单句循环、粤拼搜索及显示开关。
